# Todo Frontend (React)

Single-page React app to manage todos via the FastAPI backend.

Run locally:
- Install deps: npm install
- Start dev server: npm start
- App URL: http://localhost:3000

Backend:
- Expects backend at http://localhost:3001
- Ensure FastAPI server is running

Features:
- Add, list, edit, toggle complete, and delete tasks
- Inline editing on double-click or Edit
- Loading and error states
- Light, modern style with #3b82f6 and #06b6d4 accents
